Vector Enumeration

Note

This is an on-demand module. Load it with using OrbitAl.vectorenum.

A vector enumerator, after Linton, for modules of Hecke algebras given by a presentation: the coset enumerator, with cosets as basis vectors.

  • The Hecke algebra $H$ with parameter $q$ of a presentation genrel has generators $T_s$, the relations l = r of the presentation (positive words, such as braid relations), and the quadratic relations $T_s^2 = (q-1) T_s + q$.
  • The module is induced from the subalgebra $H_J$ generated by the $T_t$, $t \in J$: the first coset $x_1$ has $x_1.t = h_t x_1$, for given coefficients $h_t$. The coefficients can be scalars, such as $q$, or elements of $H_J$ itself, as HElts, acting from the left.
  • Coincidences are linear relations between the cosets, handled by linear Union-Find. A relation is solved for a coset with a unit coefficient; a relation without one waits until further reductions provide one.

New cosets are defined in breadth-first order, and each relator is applied at each coset, giving deductions where only one entry is unknown. For Coxeter groups, this defines exactly $|W : W_J|$ cosets (Deodhar), without coincidences.

julia> using OrbitAl, OrbitAl.presentations, OrbitAl.vectorenum

julia> q = 2//1;

julia> V = vector_enum(presentations.A3, q, [1, 2], [q, q]);

julia> length(active_cosets(V))
4

OrbitAl.vectorenum.vector_enum — Function
vector_enum(genrel, q, J, Jcoef; defs = [])

Enumerate a basis of the module $H \otimes_{H_J} M$ of the Hecke algebra $H$ with parameter q of the presentation genrel (with fields gens and rels, the relations l = r holding in $H$ for the $T_s$, alongside the quadratic relations $T_s^2 = (q-1)T_s + q$). The generators J act on the first coset $x_1$ as the coefficients Jcoef: scalars, such as q, or elements of the Hecke algebra $H_J$, such as HElts, acting from the left.

New cosets are defined in breadth-first order, or along the words defs first, where possible. Returns a VectorTable. A relation without a unit coefficient waits; if any are left at the end, the active cosets span the module but need not be a basis.

OrbitAl.vectorenum.VectorTable — Type
VectorTable{C}

A vector table under construction, with coefficients of type C. The cosets 1, 2, 3, ... are basis vectors $e_1, e_2, e_3, \dots$; next[x][s] is the image $e_x.s$, as a SparseVec, or nothing if not yet known. parent holds the linear relations between the cosets (see OrbitAl.unionfind), dead the rows (i, s, w) of eliminated cosets, which still have to be satisfied, pending the relations that have no unit coefficient (yet), and words[x] is the word that defined coset x.

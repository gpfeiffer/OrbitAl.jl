Union-Find

Note

This is an on-demand module. Load it with using OrbitAl.unionfind.

Union-Find maintains an equivalence relation that grows by adding relations one at a time, and answers whether two elements are equivalent. It comes in two versions, as two methods each of find and unite!:

  • Union-Find, for an equivalence relation on 1:n generated by pairs. A forest parent has parent[i] == i for the roots; each class is a tree, and its root is its smallest element.
  • Linear Union-Find, for linear relations between the basis vectors $e_1, e_2, \dots$, given as SparseVecs. A dictionary parent maps each inactive position i to the vector that replaces $e_i$. find computes canonical forms modulo the relations.

In both versions, unite! returns the element that has become inactive, or 0 if the relation adds nothing. Union-Find is the special case of linear Union-Find for the relations $e_i = e_j$.

Linear Union-Find solves a relation for its last position with a unit coefficient: over a field, simply its last position. The coefficients may also come from a ring, even a non-commutative one acting from the left, such as a Hecke algebra. Such a coefficient type adds a method to isunit, and unite! returns -1 for a relation that has no unit coefficient.

julia> using OrbitAl.unionfind, OrbitAl.sparsevec

julia> forest = collect(1:5);

julia> unite!(forest, 2, 5), unite!(forest, 5, 4), unite!(forest, 4, 2)
(5, 4, 0)

julia> find(forest, 5)
2

julia> e(i) = unitVec(Rational{Int}, i);

julia> parent = Dict{Int, SparseVec{Rational{Int}}}();

julia> unite!(parent, e(4), e(1) + e(3)), unite!(parent, e(3), 2 * e(2))
(4, 3)

julia> find(parent, e(4))
e1 + (2)e2

The coset enumerator in OrbitAl.enumerator adds methods for coset tables: Union-Find with consequences.

Find and Unite

OrbitAl.unionfind.find — Function
find(parent::Vector{Int}, i)

The root of i in the forest parent is the smallest element of its class.

source
find(parent::Dict, v::SparseVec)

The canonical form of v modulo the relations in parent: the unique vector in v + U that involves active positions only, where U is the subspace (or submodule) spanned by the relations, provided that unite! could solve each of them.

source
OrbitAl.unionfind.unite! — Function
unite!(parent::Vector{Int}, i, j)

Add the relation i ~ j to the forest parent: the larger root points to the smaller one. Returns the larger root, which is no longer a root, or 0 if i and j were in the same class already.

source
unite!(parent::Dict, u::SparseVec, w::SparseVec)

Add the relation u = w to parent: reduce u - w, and solve the result for its last position with a unit coefficient (see isunit), which then becomes inactive. Returns that position, or 0 if the relation follows from the earlier ones, or -1 if no coefficient is a unit, so that the relation cannot be solved (yet).

Coefficients multiply from the left, so that the coefficients may come from a non-commutative ring, acting on the left.

source
OrbitAl.unionfind.isunit — Method
isunit(x::Zn)

Whether x is a unit: whether its residue is coprime to the modulus. For a prime modulus, this means x is not zero.

source
isunit(c)

Whether the coefficient c is invertible. The default, !iszero(c), is right for fields; coefficient types with non-units add their own method.

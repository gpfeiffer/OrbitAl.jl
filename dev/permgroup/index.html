Permutation Groups

This module provides lightweight permutation groups built on top of the orbit algorithms. A group is defined by a list of generators and an identity element. The abstract type APermGp asks its subtypes for sizeOfGroup, memberOfGroup and randomGroupElement, and builds the generic algorithms (elements, conjugacy classes, subgroups, intersections) on them. PermGp computes these three by orbit computations, as in Part 1 of the notebooks; SimsGp and CoxeterGp use a stabilizer chain instead.

Types

OrbitAl.permgroup.APermGp — Type
APermGp

Abstract supertype for all permutation group types. A subtype has fields gens and one, and methods for sizeOfGroup(G), memberOfGroup(G, perm) and randomGroupElement(G), which size, in and rand call. The generic algorithms on APermGp, such as elements, conjClasses and ∩, use only these.

source
OrbitAl.permgroup.PermGp — Type
PermGp(gens, one)

A permutation group with generators gens::Vector{Perm} and identity element one.

Examples

julia> using OrbitAl

julia> s = Perm([2,1,3]); t = Perm([1,3,2]);

julia> G = PermGp([s, t], one(s));

julia> sizeOfGroup(G)
6

Return true if perm belongs to group, using a recursive sifting algorithm.

Intersection

Base.intersect — Method
intersect(G, H)
G ∩ H

Return generators of G ∩ H by a BFS through H's Cayley graph from the identity. A Dict tracks visited elements with value 0 (in the current K at discovery: marked seen but not queued), 1 (in G: queued and added as a new generator of K), or 2 (not in G: queued as a coset representative). Skipping elements of K is safe: for z ∈ K and b ∈ H.gens, either b ∈ G (hence b ∈ K, so z*b ∈ K already) or b ∉ G (so z*b ∉ G). Elements of non-trivial cosets of K in H lie outside K and are therefore always queued on first encounter, so every coset of K in H is represented in the queue. Not all elements of H need be visited.

Examples

julia> using OrbitAl

julia> s = Perm([2,1,3,4]); t = Perm([1,3,2,4]); u = Perm([1,2,4,3]);

julia> G = PermGp([s, t], one(s));  # S3 on {1,2,3}, order 6

julia> H = PermGp([t, u], one(s));  # S3 on {2,3,4}, order 6

julia> K = G ∩ H;

julia> elements(K)
2-element Vector{Perm}:
 Perm([1, 2, 3, 4])
 Perm([1, 3, 2, 4])

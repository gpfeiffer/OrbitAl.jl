Schreier-Sims Groups

Note

This is an on-demand module. Load it with using OrbitAl.simsgroup.

This module is the code of Part 5 of the notebooks: the Schreier-Sims algorithm, which computes a stabilizer chain with a strong generating set, and backtrack search through the elements of a group along such a chain. A SimsGp is a permutation group whose stabilizer chain is computed on first use, for fast size computations and membership tests without enumerating its elements.

Stabilizer Chains

OrbitAl.simsgroup.Link — Type
Link(point, gens, id)

A link of a stabilizer chain: the base point, the generators gens of the stabilizer of the earlier base points, the orbit of point under them, and a transversal reps, which maps each point y of the orbit to an element taking point to y.

source
OrbitAl.simsgroup.sift — Function
sift(chain, g, i = 1)

Sift the permutation g through the links i, i+1, ... of chain. Return the residue and the first link where the image of the base point is not in the orbit (or length(chain) + 1). g lies in the group if and only if it sifts through with residue the identity.

A stabilizer chain, as a list of Links, of the group generated by gens, by the Schreier-Sims algorithm. The base starts with the points in base.

The functions sizeOfGroup, memberOfGroup and randomGroupElement work on a stabilizer chain. For an ASimsGp, such as a SimsGp or a CoxeterGp, they use its chain, and size(G), in(g, G) and rand(G) call them.

The order of the group with stabilizer chain chain, as a BigInt: the product of the orbit lengths along the chain.

A uniformly distributed random element of the group with stabilizer chain chain and identity id: a product of random elements of the transversals of the chain.

Backtrack Search

OrbitAl.simsgroup.backtrack — Function
backtrack(chain, id, accept, prune = (g, i) -> true)

Search the elements of the group $G$ with stabilizer chain chain depth first, for those with accept(g). The elements form a tree, whose nodes at depth $i$ are the cosets $G^{(i+1)} h$ of the stabilizers in the chain, each represented by a partial product h. A node at depth i is skipped, together with the subtree below it, unless prune(h, i). Returns the elements found, and the number of nodes visited.

source
OrbitAl.simsgroup.subgp_gens — Function
subgp_gens(chain, accept, prune = (g, i) -> true)

Generators of the subgroup $K = \{g ∈ G : accept(g)\}$ of the group $G$ with stabilizer chain chain, by backtrack search, from the end of the chain back to its start. At link $i$, a point already in the orbit of the base point under the generators found so far needs no search. accept must define a subgroup, and prune must not skip a node with an element of $K$ below it.

source
Base.intersect — Method
intersect(G::ASimsGp, H::ASimsGp)
G ∩ H

The intersection of G and H, as a SimsGp with generators found by subgp_gens: a node at depth $i$ in the tree of $G$ is pruned unless it sifts through the first $i$ links of a stabilizer chain of $H$ with the same base.

Examples

julia> using OrbitAl, OrbitAl.simsgroup

julia> s = Perm([2,1,3,4]); t = Perm([1,3,2,4]); u = Perm([1,2,4,3]);

julia> G = SimsGp([s, t], one(s));  # S3 on {1,2,3}, order 6

julia> H = SimsGp([t, u], one(s));  # S3 on {2,3,4}, order 6

julia> K = G ∩ H;

julia> size(K)
2

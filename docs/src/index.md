# OrbitAl.jl

Welcome to the documentation for `OrbitAl.jl`, a Julia package for working with permutations and orbits in a simple and composable way, and for the algorithms built on them, up to coset enumeration and vector enumeration for Hecke algebras.

## Core modules

Loaded automatically with `using OrbitAl`:

- [Permutations](permutation.md)
- [Orbits](orbits.md)
- [Permutation Groups](permgroup.md)

## On-demand modules

Load explicitly, e.g. `using OrbitAl.syt`:

- [Coxeter Groups](coxeter.md) — `using OrbitAl.coxeter`
- [Schreier-Sims Groups](simsgroup.md) — `using OrbitAl.simsgroup`
- [Standard Young Tableaux](syt.md) — `using OrbitAl.syt`
- [Cosets](coset.md) — `using OrbitAl.coset`

## Features

### Core

- **Permutations** — `Perm` type with full arithmetic: composition `*`, inversion `inv`, power `^`, conjugation, cycle decomposition, sign, order.
- **Orbit engine** — BFS-based orbit algorithms in 10+ variants: with words, transversals, stabilizers, Schreier generators, edges, images, and multi-seed (`orbitx`) forms.
- **Standard actions** — `onPoints`, `onRight`, `onSets`, `onPairs`, `onWords` ready to use or compose.
- **Permutation groups** — `PermGp` supporting element enumeration, conjugacy classes, subgroup enumeration, membership testing, random element sampling, and intersection.
- **Visualization** — D3.js force-directed Cayley graphs rendered in Jupyter notebooks.

### On-demand

- **Coxeter groups** — `CoxeterGp` built from a Cartan matrix: root systems, reflections, Coxeter length, reduced words, parabolic subgroups and transversals, conjugacy classes.
- **Schreier-Sims groups** — `SimsGp` with cached stabilizer chain for fast repeated membership tests and size computation without enumerating all elements.
- **Standard Young tableaux** — partitions, Newton sums and differences, composition/subset conversions, tableau paths.
- **Cosets** — `Coset` type and `cosets` for orbit enumeration of right cosets of a subgroup.
- **Involutions** — actions and orbit algorithms for involutions and their conjugacy classes in Coxeter groups.
- **Modular arithmetic** — `Zp{p}`: the field of residues modulo a prime `p`, with the modulus in the type, ready as coefficients for sparse vectors, Union-Find and spinning.
- **Sparse vectors** — `SparseVec`: the positions and values of the nonzero coefficients, over any coefficient ring, with no fixed length.
- **Union-Find** — for equivalence relations, as a forest, and for linear relations between basis vectors (linear Union-Find), solving for unit coefficients when the coefficients come from a ring.
- **Hecke algebras** — `HeckeAlg` and `HElt`: Iwahori-Hecke algebras of finite Coxeter groups in the basis ``T_w``, with monomial units and their inverses.  The elements of the group are not stored, so `W` can be as large as ``E_8``.
- **Linear orbit algorithms** — spinning: a basis of the subspace generated by a vector under matrices, via linear Union-Find, and the action on that basis (`spinning_with_images`).
- **Coset enumeration** — a Todd-Coxeter coset enumerator, `coset_table`, built from the orbit algorithm, Union-Find and relation variants, with example presentations in `OrbitAl.presentations`.
- **Vector enumeration** — a vector enumerator after Linton, `vector_enum`, for modules of Hecke algebras induced from parabolic subalgebras ``H_J``, with scalars or elements of ``H_J`` as coefficients.

## Usage

### Permutations

```julia
using OrbitAl

p = Perm([2, 3, 1])          # 3-cycle
q = inv(p)
p * q == one(p)              # true
shape(p)                     # [3]
order(p)                     # 3
```

### Orbits

```julia
using OrbitAl

s = Perm([2, 1, 3, 4])       # transposition (1 2)
t = Perm([2, 3, 4, 1])       # 4-cycle (1 2 3 4)

orbit([s, t], 1, onPoints)   # [1, 2, 3, 4]
```

### On-demand: Coxeter groups

```julia
using OrbitAl, OrbitAl.coxeter

W = CoxeterGp(cartanMat("A", 3))   # symmetric group S4 as a Coxeter group
sizeOfGroup(W)                      # 24
length(coxeterConjugacyClasses(W))  # 5 (partitions of 4)
```

### On-demand: Coset enumeration

```julia
using OrbitAl, OrbitAl.presentations, OrbitAl.enumerator

T = coset_table(presentations.G12, presentations.G12.sbgp)
T.active                     # 24 cosets
sizeOfGroup(PermGp(T))       # 48: the order of the group acting on them
```

### On-demand: Vector enumeration

```julia
using OrbitAl.presentations, OrbitAl.vectorenum, OrbitAl.coxeter, OrbitAl.hecke

q = 2//1
H = HeckeAlg(CoxeterGp(cartanMat("A", 2)), q)          # H_J, for J = {1, 2}
V = vector_enum(presentations.A3, q, [1, 2], [Tw(H, 1), Tw(H, 2)])
length(active_cosets(V))     # 4 = |W : W_J|
V                            # the table, with entries such as x2.3 = (2)x1 + x2
```

### On-demand: Schreier-Sims

```julia
using OrbitAl.simsgroup

size(cube)   # order of Rubik's cube group
```

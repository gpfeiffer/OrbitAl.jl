# Vector Enumeration

!!! note
    This is an on-demand module. Load it with `using OrbitAl.vectorenum`.

A vector enumerator, after Linton, for modules of Hecke algebras given by a
presentation: the [coset enumerator](@ref Coset-Enumeration), with cosets as
basis vectors.

- The **Hecke algebra** ``H`` with parameter ``q`` of a presentation `genrel`
  has generators ``T_s``, the relations `l = r` of the presentation (positive
  words, such as braid relations), and the quadratic relations
  ``T_s^2 = (q-1) T_s + q``.
- The **module** is induced from the subalgebra ``H_J`` generated by the
  ``T_t``, ``t \in J``: the first coset ``x_1`` has ``x_1.t = h_t x_1``, for
  given coefficients ``h_t``.  The coefficients can be scalars, such as ``q``,
  or elements of ``H_J`` itself, as [`HElt`](@ref OrbitAl.hecke.HElt)s, acting
  from the left.
- **Coincidences** are linear relations between the cosets, handled by linear
  [Union-Find](@ref).  A relation is solved for a coset with a unit
  coefficient; a relation without one waits until further reductions provide
  one.

New cosets are defined in breadth-first order, and each relator is applied at
each coset, giving deductions where only one entry is unknown.  For Coxeter
groups, this defines exactly ``|W : W_J|`` cosets (Deodhar), without
coincidences.

```jldoctest
julia> using OrbitAl, OrbitAl.presentations, OrbitAl.vectorenum

julia> q = 2//1;

julia> V = vector_enum(presentations.A3, q, [1, 2], [q, q]);

julia> length(active_cosets(V))
4

julia> V.words

 [3, 2, 1]

julia> using OrbitAl.coxeter, OrbitAl.hecke

julia> H = HeckeAlg(CoxeterGp(cartanMat("A", 2)), q);
```
